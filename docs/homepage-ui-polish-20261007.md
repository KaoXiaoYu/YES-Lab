# 首页姓名、导航与鼠标背景动效

## 需求与范围

- 成员卡片姓名保持突出，并按用户要求与头像背景形成反色效果。
- 首页背景增加轻量的鼠标跟随光晕，仅用于装饰，不改变栏目和业务接口。
- 修正主导航“讨论板”与其余栏目文字的垂直对齐。
- 用户追加要求：成员顶栏按实际可用宽度显示全部入口，仅超出宽度的入口进入“更多”，不再固定折叠个人主页等入口。

## 实现方案（用户已确认：按此方案实现）

- 姓名显式使用白色前景，并以 `mix-blend-mode: difference` 与卡片底图反色；增加轮廓以帮助复杂背景上的辨识。浏览器不支持混合模式时保持白字与深色渐变底。
- 首页独立装饰层采用淡蓝/淡紫径向光晕，位于内容后面；`pointer-events: none`，不遮挡点击、不修改头像或 Logo。
- 仅桌面精细鼠标启用；用 `requestAnimationFrame` 合并更新，仅修改 transform/opacity，不触发 Vue 每帧渲染。鼠标离开、页面隐藏时停止；卸载时清理事件和帧请求。
- 用户追加“更 Q 弹”的要求：位置改为欠阻尼弹簧跟随（刚度 180、阻尼 12），快速移动时轻微沿速度方向拉伸（上限 12%），停下后越过目标并回弹收敛。按时间积分且子步不超过 1/120 秒；稳定后停止帧循环，重新进入时从鼠标位置初始化。
- 用户追加“移动时变色”：根据光晕实际移动距离累计色相，每像素 0.18 度，通过装饰层 hue-rotate 在蓝紫粉青间循环；停稳保留当前颜色，不持续自行变色，不修改正文/Logo/头像颜色。这里按用户要求增加 filter 更新，其余内容仍不参与动画。
- 手机/粗指针与 `prefers-reduced-motion: reduce` 停用跟随。亮暗主题分别控制光晕强度；键盘操作和阅读不依赖动效。
- 导航链接和按钮统一为 44px 最小高度、相同 flex 居中与行高。
- 成员顶栏通过 ResizeObserver 测量容器与同样样式的不可交互测量项；预留账号、后台管理和必要的“更多”宽度。屏幕大小、字体和账号变化时重新计算，保留原权限、路由、菜单键盘行为，不增加后台接口。

## 验收

- Chrome 截图：1440/375 亮暗，另检查 768/1024 布局。
- 检查姓名在深色、浅色与复杂图片上的辨识度，导航文字同一水平线。
- 检查鼠标移动/离开、减少动态、粗指针、页面隐藏与卸载清理；构建检查通过。
- 不涉及数据库迁移、服务器数据、任务流程或生产部署。
